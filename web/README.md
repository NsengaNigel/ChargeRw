# ChargeRW — Web

React + Vite + TypeScript frontend for ChargeRW.

## Setup

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build → dist/
npm run preview  # preview the production build locally
```

Works without the backend — falls back to mock station data automatically.

See the [root README](../README.md) for full project setup including the backend and deployment.
